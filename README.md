# pair-wise-yf-54 博物馆展品点交与布展条件核验

## 源提示词摘要
策展人、保管员、布展负责人和借展方从到场点交、环境条件检查、安装位置确认到闭展归还共同处理展品。系统记录条件、附件、风险等级、照片说明、处理意见和签字结果，差异项未解决时不能进入下一阶段，并支持大量展品与断网暂存。

## 技术栈
Vue 3 + TypeScript + Vite + Vuetify + Pinia + Vue Router + Axios + VueUse + VeeValidate + Zod + Vue I18n。

## 已实现闭环
- 展品、环境检查、差异项三类业务对象。
- 到场点交、布展核验、闭展归还的分阶段签字与推进门禁。
- 未解决差异阻断流转，可单独确认解决。
- `v-virtual-scroll` 大列表、离线队列提示、手动确认同步。
- localStorage 持久化。

## 断网暂存与多终端合并
- 每台终端断网期间把环境读数与差异项暂存为一个离线批次，网络恢复后同时提交。
- 按采集时间逐字段合并（非按提交顺序覆盖）：同时间窗内读数一致时取采集时间更晚者，晚到的记录不会盖掉先到的。
- 同时间窗内读数互相矛盾时两条都留下，整批保留为「冲突」，并标出终端与采集时间点，不丢弃任何一方。
- 合并失败（如上报了系统中不存在的展品）时该条记录连同整批保留，注明终端与时间点。
- 合并后环境读数更新会使原来的通过判定失效：展品退回「待复核」并写明原因，已签过的字保留、无需重签。
- 顶部「模拟多终端同时提交」可构造 TERM-01/02/03 三个终端批次（含一致更新、读数矛盾、未知展品失败三种情形），再点「合并同步」查看合并结果。
