# pair-wise-yf-54 博物馆展品点交与布展条件核验

## 源提示词摘要
策展人、保管员、布展负责人和借展方从到场点交、环境条件检查、安装位置确认到闭展归还共同处理展品。系统记录条件、附件、风险等级、照片说明、处理意见和签字结果，差异项未解决时不能进入下一阶段，并支持大量展品与断网暂存。

## 技术栈
Vue 3 + TypeScript + Vite + Vuetify + Pinia + Vue Router + Axios + VueUse + VeeValidate + Zod + Vue I18n。

## 已实现闭环
- 展品、环境检查、差异项三类业务对象。
- 到场点交、布展核验、闭展归还的分阶段签字与推进门禁。
- 未解决差异阻断流转，可单独确认解决。
- `v-virtual-scroll` 大列表、离线队列提示、手动确认同步。
- localStorage 持久化。
- 断网多终端暂存恢复合并（`src/services/merge.ts`）：
  - 温度/湿度/照度按字段、按采集时间逐字段合并，读数历史完整保留；
  - 同字段同采集时间点读数矛盾时各终端读数双留并标红，后到不覆盖先到，当前值停在最后一致读数；
  - 合并后读数实际更新且原判定为“通过”的展品退回“待复核”，写明字段变化与终端来源，已有签字不重签、待复核期间不能推进；
  - 同标题差异项跨终端归并来源，定级矛盾时两条都留；校验失败、未知展品、读数/差异矛盾的离线批次整批保留，冲突记录标明终端、时间点与批次号，支持重试与线下处置后移出。
